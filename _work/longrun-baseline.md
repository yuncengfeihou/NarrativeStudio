# 长跑评测基准（冻结于 2026-10-27 03:40，开跑前）

> 目的：在**真实上游**下跑一局 ≥40 轮的长篇剧情，用一份**开跑前定好**的判据回答三个问题：
> 长轮次下剧情质量会不会塌、记忆会不会散、上下文增量是否可控，以及稳定性/走向/成本是否可接受。
>
> 冻结纪律：本文件的判据与阈值在开跑后**不再修改**。任何事后调整都必须写进 §9 变更记录，
> 并同时说明「为什么原判据不适用」——不允许悄悄改阈值让结论变好看。
>
> 分工：**机械阈值只有一份主人**，在 `_work/longrun-report.mjs` 顶部 `TH`（每条带依据）。
> 本文件不复制那些数字，只定义**它们没覆盖的维度**（人工评分 rubric、预注册探针、判定合成）。
> 这是 AGENTS.md §16「同一类信息只有一个主人」的直接应用。

## 3. 预注册记忆探针（开跑前写死，不许事后补）

设计原则：**卡上没有、只有长程记忆能答对**。所以不用「黎婆 76 岁」这种卡里就写着的事实，
而是用我在某一拍**临时种下**的细节，隔 15–25 拍再回指。

| ID | 种下于 | 内容（我在行动里自然写进去） | 回指于 | 判定（正文里应出现） |
|---|---|---|---|---|
| P1 | t6 | 我在牛车底板第三块木板的缝里藏了个小布包 | t26 | 回指时不能写成「牛车上的布包」「怀里的布包」——方位错即 FAIL |
| P2 | t9 | 我管那只掉漆的旧马灯叫「老伙计」 | t31 | 正文提到马灯时用「老伙计」或明确回应这个称呼 |
| P3 | t12 | 路过张兰时我没骂她，只记下她左手腕上有只银镯 | t34 | 回指张兰时能带出「银镯」或「左手腕」，不能写成右手/无此细节 |
| P4 | t18 | 我把卖破烂的七十五块里抽出五块，压在奶奶药罐底下 | t38 | 能记得「五块」和「药罐底下」，写成「钱袋里」「全给了」即 FAIL |
| P5 | t22 | 我在村口老槐树上刻了一道印子记日子 | t44 | 记得刻痕在槐树/村口，且认得那是记日子的 |

判定口径：**命中 = 正文在不被提示的情况下正确复现方位/称呼/物件**；「提到了但写错方位」记 FAIL；
「完全没提」记 MISS。B1 要求 5/5 命中；≤3/5 记为记忆一致性 FAIL。

> 探针是「有没有真的记住」，不是「文笔好不好」。答对但写得平淡仍算命中。

## 4. 抽样与人工评分办法

- 抽样拍：t1（开场）、t5、t10、t15、t20、t25、t30、t35、t40、t45 —— 覆盖开局/早/中/晚。
- 每段读**完整正文**（不读摘要），按 §2 A1/A2/A4 打分，记 `分数 + 一句证据`。
- 全文通读首尾 5 拍 + 中段 3 拍，做 A3 逻辑硬伤扫描与 G4 剧情走向判断。
- 评分只由我（同一读者）做，避免多人标准漂移；分数不是绝对值，是**同一条线内的相对变化**。
  因此 A1/A2 额外记录「首 10 拍中位数 vs 末 10 拍中位数」——长跑要看的是**衰减**，不是绝对值。

## 5. 判定合成

1. **机械判定**：`node _work/longrun-report.mjs <session>` 的 `VERDICT`（PASS/WARN/FAIL）——
   阈值主人是脚本里的 `TH`。
2. **人工判定**：A1–A5、B1、E3、G4 由我按本文件打分。
3. **总分**：任一维度出现 FAIL → 整体 FAIL；全部维度 PASS 且 WARN ≤ 2 → 整体 PASS；
   其余 → WARN。
4. **报告必须同时给出**：每个维度的数字、判定、以及**证据片段**（原文摘录 ≤ 80 字）。
   只给结论不给证据的判定无效。

## 6. 已知的口径陷阱（写在这里，防止事后自欺）

- `meta.recall.rate` 恒 ≈ 100%，它是**索引饱和度**，不衡量叙事有没有用到卡。
  叙事覆盖率看正文点名率（`longrun-report.mjs` 第 2 段「叙事点名」）。
- 送模体积随轮次线性增长是**设计目标**（AGENTS §6.3 被改写过两次），不是隐患。
  斜率 > 0 是 PASS 条件。
- `cached_tokens` 恒 0 先怀疑上游没开缓存，别急着算成「我们的缓存策略坏了」。
- 3-gram 重复率会因**专名复用**（「伍卿」「凌玥」）天然偏高，阈值给宽了；它是启发式。
- 4 轮基线只在短会话上成立，长跑的 FAIL 不能用它的结论解释。
